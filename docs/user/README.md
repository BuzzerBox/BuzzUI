# BuzzerBox user guide

For people who host a quiz with a BuzzerBox. You need no technical knowledge; the BuzzerBox brings its own WiFi and
needs no internet.

1. [Quick start](quick-start.md): set up the box and start a game. One page, to print and keep with the box.
2. [Hosting a game](hosting-a-game.md): game master and screens, teams and buzzers, grading, media, pausing and ending.
3. [Creating games](creating-games.md): the editor, questions and media, the look of the screen, and moving games
   between boxes.
4. [Wireless buzzers](wireless-buzzers.md): adopting them, case colors, charging, and what their lights mean.
5. [Box settings and updates](box-settings-and-updates.md): the WiFi name and password, and installing updates.
6. [Troubleshooting](troubleshooting.md): no picture, no connection, a buzzer that doesn't react, a video that stutters.

Auf Deutsch: [Benutzerhandbuch](de/README.md).

**About the language.** The BuzzerBox speaks German and English. It starts in German; choose *Language* (*Sprache*)
on the first page or in the game master's toolbar, and the screens follow. This guide uses the English names of the
buttons and gives the German ones in parentheses where it helps, for example *New game* (*Neues Spiel*).
